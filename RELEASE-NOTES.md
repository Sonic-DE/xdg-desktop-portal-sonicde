# XDG Desktop Portal for SonicDE Release Notes

Gives sandboxed apps (such as Flatpaks) and other programs SonicDE's own file pickers, screen sharing, screenshots and permission prompts.

## Unreleased

- Now presents itself with SonicDE names and identity throughout the desktop.

## 6.8.0 (2026-10-20)

- Checking your connected screens no longer makes Nvidia graphics cards reconfigure your displays.
- Behind the scenes: updated to build against SonicDE 6.8.0 and a version number update.

## 6.7.5.1 (2026-09-18)

- Checking your connected screens no longer makes Nvidia graphics cards reconfigure your displays.

## 6.7.5 (2026-09-12)

- Fewer legacy compatibility packages are needed: the old Plasma and Qt 5 support libraries are no longer required.
- Behind the scenes: version number update.

## 6.7.4.1 (2026-08-30)

- The USB device access prompt and other portal dialogs now open properly attached to the app that asked for them.
- Behind the scenes: added automated tests for the file picker and USB prompts.

## 6.7.4 (2026-08-03)

No SonicDE-specific changes in this release; it brings the package up to date with upstream.

## 6.7.3.2 (2026-08-02)

- The KDE logo has been replaced with the SonicDE logo throughout.

## 6.7.3.1 (2026-07-19)

- Now built for SonicDE's X11 desktop, with Wayland parts replaced by X11 equivalents.
- Behind the scenes: improved code formatting and developer tooling.
